# Requirements Audit

## Objetivo

Revisar requisitos de un proyecto pequeno para detectar ambiguedades antes de construir o probar.

## Problema

Muchos errores nacen porque el pedido inicial es incompleto o contradictorio.

## Entregables

- Lista de requisitos.
- Preguntas pendientes.
- Riesgos detectados.
- Criterios de aceptacion.

## Herramientas

Markdown, QA manual y analisis logico.

## Servicio relacionado

QA preventivo, documentacion tecnica y soporte de producto.
