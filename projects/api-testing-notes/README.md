# API Testing Notes

## Objetivo

Documentar pruebas manuales para endpoints simples.

## Problema

Las APIs necesitan validar respuesta, estado, datos esperados y manejo de errores.

## Entregables

- Lista de endpoints.
- Casos positivos.
- Casos negativos.
- Resultado esperado.
- Observaciones.

## Herramientas

Postman conceptual, Markdown, JSON y QA manual.

## Servicio relacionado

QA tecnico junior, documentacion de APIs y soporte de testing.
