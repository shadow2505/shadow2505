# Case Study: API Testing Notes

## Resumen

Proyecto demostrativo para documentar pruebas manuales de servicios web. Muestra orden, criterio y capacidad para validar respuestas.

## Objetivo

Crear una plantilla de QA tecnico junior para revisar servicios simples.

## Tabla de pruebas

| Servicio | Metodo | Caso | Esperado | Estado |
|---|---|---|---|---|
| acceso | POST | datos validos | respuesta correcta | pendiente |
| acceso | POST | campos vacios | mensaje claro | pendiente |
| listado | GET | consulta normal | lista de datos | pendiente |
| detalle | GET | elemento inexistente | respuesta de no encontrado | pendiente |

## Proceso

1. Identificar servicios.
2. Definir metodo.
3. Crear casos positivos.
4. Crear casos negativos.
5. Revisar estructura de respuesta.
6. Documentar resultado.

## Entregables

- matriz de servicios,
- casos positivos y negativos,
- resultado esperado,
- errores encontrados,
- observaciones.

## Servicio relacionado

QA tecnico junior, documentacion de APIs y soporte de pruebas manuales.

## Mejoras futuras

- coleccion de pruebas,
- ejemplos JSON,
- automatizacion basica,
- reporte final.
