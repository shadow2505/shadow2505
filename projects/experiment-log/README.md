# Experiment Log

Documentar pruebas, hipotesis, fallas y ajustes de un prototipo fisico.

## Entregables

- Bitacora de pruebas.
- Variables observadas.
- Fallas detectadas.
- Ajustes realizados.
- Conclusion tecnica.

## Herramientas

Markdown, tablas y metodo experimental.

## Servicio relacionado

Documentacion tecnica, reporte de pruebas y analisis de fallas.
