# Route Risk Matrix

## Objetivo

Evaluar rutas, costos, riesgos y prioridades para un viaje largo.

## Problema

Una ruta sin matriz de decision puede ignorar seguridad, presupuesto, documentos y tiempos.

## Entregables

- Tabla de etapas.
- Riesgos por zona.
- Prioridad.
- Mitigacion.
- Presupuesto estimado.

## Herramientas

Markdown, CSV, investigacion y analisis de riesgos.

## Servicio relacionado

Research, planeacion, organizacion de informacion y matrices de decision.
