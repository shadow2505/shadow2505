# Landing Page Kit

## Objetivo

Crear una plantilla base para paginas de servicios, portafolios o negocios pequenos.

## Problema

Muchos clientes necesitan presencia web rapida, simple y clara.

## Entregables

- Estructura HTML.
- Estilos CSS responsive.
- Secciones de servicios, beneficios y contacto.
- Checklist de publicacion.

## Herramientas

HTML, CSS, JavaScript basico y GitHub Pages.

## Servicio relacionado

Front-end basico y landing pages.
