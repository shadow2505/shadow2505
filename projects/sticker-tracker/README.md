# Sticker Tracker

## Objetivo

Crear un sistema simple para controlar faltantes, repetidos y avance de una coleccion.

## Problema

Cuando hay varias listas, es facil duplicar datos o perder seguimiento.

## Entregables

- Tabla por persona.
- Lista de faltantes.
- Lista de repetidos.
- Indicador de avance.
- Formato listo para marcar.

## Herramientas

Google Sheets, CSV y Markdown.

## Servicio relacionado

Data entry, organizacion de listas y control de inventario pequeno.
