# QA Lab

Proyecto demostrativo para mostrar estructura basica de reporte QA.

## Objetivo

Presentar bugs clasificados por area, severidad, pasos y resultado esperado.

## Habilidades demostradas

- QA Manual.
- Web testing.
- Documentacion de errores.
- Clasificacion por severidad.
- HTML y CSS basico.

## Mejoras futuras

- Filtro por severidad.
- Formulario para agregar bugs.
- Exportacion a CSV.
- Capturas de evidencia.
