# Mini CRM Sheet

## Objetivo

Crear una tabla sencilla para controlar clientes, propuestas, estado y siguiente accion.

## Problema

Sin seguimiento, una oportunidad se pierde aunque el trabajo sea bueno.

## Entregables

- Tabla de contactos.
- Estado de propuesta.
- Fecha de seguimiento.
- Valor estimado.
- Notas.

## Herramientas

Google Sheets, CSV y Markdown.

## Servicio relacionado

Asistente virtual, operaciones y control comercial basico.
