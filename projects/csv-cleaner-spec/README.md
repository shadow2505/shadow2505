# CSV Cleaner Spec

## Objetivo

Definir reglas para limpiar archivos CSV antes de analizarlos o importarlos.

## Problema

Los CSV suelen traer columnas repetidas, fechas mezcladas, espacios extra y valores vacios.

## Entregables

- Reglas de limpieza.
- Tabla antes y despues.
- Checklist de validacion.
- Archivo de muestra.

## Herramientas

CSV, Google Sheets, SQL basico y Markdown.

## Servicio relacionado

Data cleaning, data entry y soporte de reportes.
