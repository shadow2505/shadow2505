# Job Application Kit

## Objetivo

Reducir el tiempo necesario para aplicar a trabajos remotos junior mediante materiales reutilizables y un proceso de seguimiento.

## Problema

Preparar desde cero una biografía, una propuesta y un enlace de portafolio para cada vacante hace que la búsqueda sea lenta e inconsistente.

## Entregables

- biografía corta,
- pitch de 30 segundos,
- propuesta para QA Manual,
- propuesta para Data Cleaning,
- propuesta para landing pages,
- checklist antes de enviar,
- tracker de seguimiento.

## Proceso

1. Identificar el tipo de vacante.
2. Seleccionar evidencia relevante.
3. Adaptar la propuesta sin inventar experiencia.
4. Revisar requisitos obligatorios.
5. Registrar la postulación.
6. Programar seguimiento.

## Evidencia

El kit se conecta con los casos de QA Lab, Finance Control Demo, Document QA y Landing Page Kit.

## Servicio relacionado

Preparación de perfiles freelance, organización de postulaciones y documentación profesional.
