# Case Study: Accessibility Checklist

## Resumen

Proyecto demostrativo para revisar accesibilidad basica en sitios pequenos. Muestra criterio de QA web mas alla de que la pagina solo se vea bonita.

## Problema

Una pagina puede verse moderna y aun asi ser dificil de usar. La revision basica de accesibilidad ayuda a detectar problemas antes de publicar.

## Objetivo

Crear un checklist simple para evaluar elementos comunes en una landing page.

## Checklist

| Area | Revision | Resultado |
|---|---|---|
| Contraste | texto legible sobre fondo | pendiente |
| Imagenes | texto alternativo si aplica | pendiente |
| Formularios | etiquetas visibles | pendiente |
| Navegacion | uso con teclado | pendiente |
| Encabezados | orden logico | pendiente |
| Links | texto descriptivo | pendiente |
| Botones | accion clara | pendiente |

## Proceso

1. Revisar estructura HTML.
2. Probar navegacion con teclado.
3. Validar contraste visual.
4. Revisar etiquetas de formulario.
5. Confirmar textos descriptivos.
6. Documentar problemas.

## Entregables

- checklist completado,
- errores encontrados,
- prioridad,
- recomendacion por punto,
- resumen final.

## Servicio relacionado

QA web, revision de landing pages y mejoras basicas de accesibilidad.

## Mejoras futuras

- pagina demo con errores intencionales,
- comparacion antes y despues,
- capturas de evidencia,
- reporte en PDF.
