# Accessibility Checklist

## Objetivo

Crear una lista de revision basica para mejorar accesibilidad en sitios pequenos.

## Problema

Un sitio puede verse bien y aun asi ser dificil de usar para muchas personas.

## Entregables

- Checklist de contraste.
- Revision de textos alternativos.
- Navegacion con teclado.
- Etiquetas en formularios.
- Orden de encabezados.

## Herramientas

HTML, QA manual, navegador y checklist.

## Servicio relacionado

QA web, revision de accesibilidad basica y mejora de landing pages.
