# Case Study: Vanlife Budget Planner

## Resumen

Proyecto demostrativo para convertir una idea grande de viaje en un sistema de presupuesto, escenarios y riesgos. Muestra investigacion, organizacion, modelado de costos y toma de decisiones.

## Problema

Un proyecto de viaje puede sonar emocionante, pero sin numeros se vuelve fantasia con llantas. Se necesitan costos por categoria, escenarios y alertas de riesgo.

## Objetivo

Crear una plantilla que estime costo mensual, costo inicial, ahorro requerido y riesgos principales.

## Categorias

| Categoria | Tipo | Nota |
|---|---|---|
| Vehiculo | inicial | compra, revision, papeles |
| Adaptacion | inicial | cama, energia, almacenamiento |
| Gasolina | mensual | depende de kilometros |
| Comida | mensual | austero, realista, comodo |
| Internet | mensual | SIM, modem, respaldo |
| Mantenimiento | variable | preventivo y correctivo |
| Emergencia | reserva | salud, grua, reparacion |
| Cruces | variable | permisos, seguros, transporte |

## Escenarios

| Escenario | Enfoque | Uso |
|---|---|---|
| Austero | minimo viable | sobrevivir y avanzar lento |
| Realista | equilibrio | ruta sostenible |
| Comodo | margen extra | menos riesgo operativo |

## Proceso

1. Definir ruta base.
2. Separar gastos iniciales y mensuales.
3. Crear tres escenarios.
4. Estimar reserva minima.
5. Identificar riesgos.
6. Crear recomendaciones.

## Entregables

- Tabla de costos.
- Matriz de riesgos.
- Checklist previo a salida.
- Version por escenario.
- Lista de decisiones pendientes.

## Servicio relacionado

Research, planeacion, organizacion de datos, presupuesto y dashboard simple.

## Mejoras futuras

- Calculadora interactiva.
- Estimador por kilometros.
- Mapa de ruta.
- Comparador de escenarios.
