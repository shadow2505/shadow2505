# Vanlife Budget Planner

## Objetivo

Crear una plantilla para estimar costos de viaje, mantenimiento, comida, internet, energia y emergencias.

## Problema

Un proyecto grande necesita escenarios. Este caso compara version austera, realista y comoda.

## Entregables

- Tabla de presupuesto mensual.
- Matriz de riesgos.
- Lista de gastos fijos y variables.
- Escenarios de ahorro.

## Herramientas

CSV, hojas de calculo, Markdown y analisis de costos.

## Servicio relacionado

Planeacion financiera, research, data organization y dashboards simples.
