# Freelance Command Center

## Objetivo

Organizar busqueda de trabajo remoto, propuestas, clientes, entregas y pagos en una tabla de seguimiento.

## Problema

Aplicar sin control provoca perdida de tiempo. Este proyecto muestra una estructura para medir avance.

## Entregables

- Tabla de postulaciones.
- Estados por cliente.
- Plantillas de propuesta.
- Indicadores semanales.
- Checklist de entrega.

## Herramientas

Google Sheets, Markdown y GitHub.

## Servicio relacionado

Asistente virtual, operaciones remotas y organizacion de proyectos pequenos.
