# Document QA

## Objetivo

Mostrar un proceso de revision documental con checklist, campos obligatorios y control de errores.

## Entregables

- Checklist.
- Tabla de campos.
- Lista de errores frecuentes.
- Flujo de revision.

## Herramientas

Markdown, hojas de calculo y revision manual.

## Servicio relacionado

Asistente virtual tecnico, data entry y control documental.
