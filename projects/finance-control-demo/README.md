# Finance Control Demo

## Objetivo

Crear un sistema demostrativo para registrar movimientos, separar cargos y abonos, medir avance y generar una lectura clara.

## Problema

Muchas personas ven estados de cuenta y no entienden que paso. Este proyecto muestra como convertir movimientos desordenados en una tabla simple.

## Entregables

- Tabla de movimientos sinteticos.
- Resumen por categoria.
- Indicadores de cargos, abonos y diferencia.
- Checklist de revision.

## Herramientas

Google Sheets, CSV, Markdown y analisis manual.

## Servicio relacionado

Limpieza de datos, data entry, reporte financiero simple y control personal.
