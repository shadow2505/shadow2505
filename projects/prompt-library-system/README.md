# Prompt Library System

## Objetivo

Organizar prompts tecnicos reutilizables para generar reportes, imagenes, documentos y respuestas profesionales.

## Problema

Sin una biblioteca, los prompts se pierden y cada tarea empieza desde cero.

## Entregables

- Categorias de prompts.
- Versiones por uso.
- Criterios de calidad.
- Ejemplos de entrada y salida.

## Herramientas

Markdown, documentacion y control de versiones.

## Servicio relacionado

Documentacion, productividad y soporte con IA aplicada.
