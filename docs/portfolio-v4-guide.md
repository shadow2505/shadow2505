# Guía del portafolio V4

## Objetivo

La versión V4 está diseñada para presentar un perfil junior serio y defendible en QA Manual, Web Testing, Data Cleaning, documentación técnica, operaciones remotas y front-end básico.

## Qué revisar antes de publicar

1. Confirmar que todos los enlaces funcionen.
2. Revisar el sitio en móvil y escritorio.
3. Validar que el correo y GitHub sean correctos.
4. Abrir cada caso principal.
5. Confirmar que los archivos CSV se descarguen.
6. Revisar ortografía y consistencia.

## Publicación en GitHub Pages

1. Fusionar la rama `portfolio-v4-ready` a `main`.
2. Abrir `Settings > Pages`.
3. Elegir `Deploy from a branch`.
4. Seleccionar `main` y `/root`.
5. Guardar.

La URL esperada es:

`https://shadow2505.github.io/shadow2505/`

## Enlace para plataformas freelance

Usar la URL pública y acompañarla con este texto:

> Portafolio con casos demostrativos de QA Manual, web testing, limpieza de datos, documentación técnica, operaciones remotas y front-end básico.

## Mantenimiento

Cada proyecto nuevo debe incluir:

- problema,
- objetivo,
- proceso,
- herramientas,
- entregables,
- evidencia,
- servicio vendible,
- siguiente mejora.
