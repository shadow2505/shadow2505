# Rubrica de calidad para proyectos

Esta rubrica ayuda a decidir si un proyecto del portafolio ya esta presentable o sigue siendo decoracion digital.

## Criterios

| Criterio | Basico | Bueno | Fuerte |
|---|---|---|---|
| Problema | existe titulo | problema claro | problema realista y especifico |
| Proceso | lista simple | pasos ordenados | decisiones explicadas |
| Entregable | README | demo o tabla | demo, datos y documentacion |
| Evidencia | texto | ejemplo | ejemplo con resultado |
| Servicio | no existe | idea general | oferta freelance clara |
| Mejora futura | no existe | una idea | roadmap tecnico |

## Puntaje sugerido

- 0 a 2: no mostrar como proyecto principal.
- 3 a 4: proyecto secundario.
- 5 a 6: proyecto principal.

## Regla

Un proyecto principal debe tener README, CASE_STUDY, datos o demo, y una explicacion de servicio vendible.
