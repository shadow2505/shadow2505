# Plantilla de caso de estudio

Usa esta estructura para que cada proyecto del portafolio no sea solo una carpeta vacia con buen nombre.

## 1. Resumen

Explicar en 3 a 5 lineas que problema resuelve el proyecto.

## 2. Contexto

- Para quien es.
- Que problema tenia.
- Por que importa.

## 3. Objetivo

Definir el resultado esperado en una frase concreta.

## 4. Proceso

1. Analisis inicial.
2. Limpieza o estructura.
3. Desarrollo o documentacion.
4. Revision de calidad.
5. Entrega final.

## 5. Herramientas

Tabla con herramientas y uso.

## 6. Entregables

Lista de archivos, documentos, tablas o demos.

## 7. Resultado

Que mejora produce el proyecto.

## 8. Servicio vendible

Como se puede convertir en oferta freelance.

## 9. Siguiente mejora

Que se agregaria para subir nivel tecnico.
