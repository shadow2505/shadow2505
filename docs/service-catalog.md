# Catalogo de servicios

## 1. Auditoria QA para sitio pequeno

**Entregable:** reporte con errores, area afectada, severidad, pasos y recomendacion.

**Incluye:**

- Navegacion principal.
- Botones.
- Formularios.
- Enlaces.
- Vista movil.
- Revision visual basica.

## 2. Limpieza de datos

**Entregable:** tabla limpia y resumen de cambios.

**Incluye:**

- Separacion de campos.
- Correccion de formatos.
- Revision de duplicados.
- Categorias consistentes.
- Observaciones finales.

## 3. Landing page basica

**Entregable:** pagina informativa simple.

**Incluye:**

- Estructura HTML.
- Estilos CSS.
- JavaScript basico.
- Secciones de servicio y contacto.
- Preparacion para GitHub Pages.

## 4. Asistente tecnico remoto

**Entregable:** apoyo operativo y documentacion.

**Incluye:**

- Captura organizada de informacion.
- Revision de documentos.
- Reportes simples.
- Control de tareas.
