# Catálogo de servicios

## 1. Auditoría QA Manual

**Ideal para:** landing pages, sitios personales y aplicaciones pequeñas.

**Incluye:**

- revisión de navegación,
- formularios,
- botones y enlaces,
- vista móvil,
- contenido y errores visuales,
- clasificación por severidad,
- pasos para reproducir.

**Entregable:** reporte en Markdown, PDF o tabla.

## 2. Limpieza de datos

**Ideal para:** CSV, Google Sheets, listas de clientes e inventarios pequeños.

**Incluye:**

- corrección de formatos,
- normalización de categorías,
- revisión de duplicados,
- campos vacíos,
- separación de columnas,
- resumen de cambios.

**Entregable:** archivo limpio, pendientes y recomendaciones.

## 3. Control documental

**Ideal para:** expedientes, solicitudes, archivos digitales y documentación administrativa.

**Incluye:**

- checklist de documentos,
- campos obligatorios,
- inconsistencias,
- estado de revisión,
- observaciones listas para copiar.

## 4. Landing page básica

**Ideal para:** perfiles, servicios y negocios pequeños.

**Incluye:**

- HTML semántico,
- CSS responsive,
- JavaScript básico,
- secciones de propuesta, servicios y contacto,
- publicación en GitHub Pages.

## 5. Asistencia técnica remota

**Incluye:**

- seguimiento de clientes y solicitudes,
- control de estados,
- plantillas,
- reportes semanales,
- organización de archivos.

## Límites

No se ofrece experiencia senior, arquitectura compleja, pentesting, automatización avanzada ni infraestructura cloud profesional. El servicio se enfoca en trabajo junior claro, delimitado y comprobable.
